# SeqShow UI / UX 规范

状态：v0.1 交互设计基线；M3 编辑器、M4 离线导出与 M5 技术验收已完成。浏览器实际范围与限制见 [M5](validation/M5.md)，公开发布单独推进。更新：2026-10-07。

范围与步骤语义见 [PRODUCT](PRODUCT.md)，数据与生命周期见 [ARCHITECTURE](ARCHITECTURE.md)，验收见 [TESTING](TESTING.md)。

## 1. 用户打开页面后看到什么

英文主文案：Turn sequence diagrams into step-by-step presentations.

页面默认加载 PRODUCT 的登录示例，首次渲染后处于总览。用户可直接按 Play，也可修改源码后 Render。初次加载按钮展示 Preparing example，渲染失败提供 Retry，不要求先读教程。

导航只保留 SeqShow 名称、简短用途、GitHub 入口。GitHub 入口指向用户创建的真实仓库 https://github.com/KunxianWang/SeqShow；本阶段不发布站点。

## 2. 桌面布局

```text
┌───────────────────────────────────────────────────────────────┐
│ SeqShow     Step-by-step sequence presentations       GitHub   │
├────────────────────────┬──────────────────────────────────────┤
│ Example [Login ▾]      │ Path [authenticated ▾]  Focus [on]    │
│ Mermaid source         │ 演示路径，条件未求值                   │
│ ┌────────────────────┐ │ ┌──────────────────────────────────┐ │
│ │ textarea           │ │ │ 全图预览：固定参与者与消息位置   │ │
│ │                    │ │ │ 当前步骤高亮，保留可读上下文     │ │
│ └────────────────────┘ │ └──────────────────────────────────┘ │
│ [Render] Supported     │ Step 0 / 6 · Overview                │
│ Diagnostics            │ Current message / note               │
│                        │ [Previous] [Play] [Next] [Reset]      │
│                        │ [Export HTML]                        │
└────────────────────────┴──────────────────────────────────────┘
```

宽度 ≥ 960 px：编辑区约 36%，预览区约 64%，编辑区最小 280 px。使用 CSS grid、min-width:0 和适当面板高度，防止长 SVG 把全页撑宽。顶部不放复杂营销栏目或功能列表。

预览区自上而下为状态提示、路径选择与 Focus、图、讲解栏（步骤类型与端点、`k / N` 与当前文本、播放控件）。桌面宽度下预览区高度限制在视口内，图区吸收剩余空间（最小 140 px，最大 720 px），使 1280×720 及以上的桌面视口无需滚动页面即可看到播放控件。可能变长的部分各有上限并在内部滚动：路径选择最多两行（视口高度 ≤ 820 px 时一行，有更多时底部显示阴影），步骤说明最多两行（高视口三行、手机四行），端点最多两行；完整文本仍在 aria-live 区域中，溢出的区域可用键盘聚焦滚动。Web 与导出文件使用同一套播放器外观。

宽度 < 960 px：编辑器在上、预览在下，控件换行。宽度 360–390 px 时按钮与分支选择仍可操作，图的横向滚动限制在预览内部。宽度较小不会静默删除参与者或自动折叠分支。

## 3. 编辑器

- 使用原生 textarea，等宽字体，明确标签 Mermaid source；首版不引入代码编辑器依赖。
- Render 明确触发编译，编辑时不逐键重渲染。
- 用户改动源码后，预览标记 Source changed — render to update；暂停播放并禁用导出。
- 示例切换先展示待加载示例；若当前源码相对上次加载或成功 Render 后有修改，提供 Replace current source / Cancel。不得选下拉框后立即丢失草稿。
- 语法说明用 Supported syntax 展开简短清单，明确这是受限兼容；Unsupported syntax 显示后置语法，不伪装成完整 Mermaid editor。
- 首版不保存云端数据，不自动传输源码。不承诺跨页面刷新保存；产品说明应提醒需要保留源码时自行复制。

## 4. 图与 Focus Mode

完整图在一次 Render 时布局。总览、播放、回退、Focus 开关和分支选择都复用相同几何位置。

| 状态 | 图中行为 | 图外说明 |
| --- | --- | --- |
| Step 0 | 所选路径正常展示；没有当前步骤 | Overview，Step 0 / N |
| Message 当前步 | 箭头及文本强调，步骤左侧显示路径内步号徽标；发送者和接收者强调 | 显示类型、完整消息与 From → To（参与者标签） |
| 自调用当前步 | 完整自调用路径强调；参与者只强调一次 | 标示 Self call 与真实端点，如 API → API（参与者标签） |
| Note 当前步 | Note 框与文字强调；相关参与者强调 | 显示 Note 文本与位置（Over / Left of / Right of 参与者标签），不生成额外解释 |
| 已讲步骤 | 使用次级线条，仍可阅读 | 不改变步骤顺序 |
| 所选路径未来步骤 | 较弱线条，保留位置与文字 | 表明尚未讲到 |
| 未选 case | 弱化；case 区域加斜纹底（路径选择器旁显示 Other path），保留 case 标签 | 不计入 N，不作为下一步 |

Focus 默认开启。Focus 关闭后完整图恢复一般展示，同时保留当前步骤的轮廓或标记与图外说明；只改变显示方式，不改变播放状态。

弱化主要作用于图形线条/背景；文字不能因降低透明度而变得难读。使用当前标记、线型和文字辅助区别，不仅靠颜色表达状态。SVG 内只改颜色和线宽，不改字重、字形或元素；步号徽标与 case 斜纹绘制在 SVG 之外的叠层，导出 SVG 与几何保持不变。

宽图至少保留渲染器给出的自然宽度，使用图内横向滚动，不把大量参与者整体压缩成不可读的小字。此宽度同时保留在离线导出中。

当前元素超出可见区域时，按当前步骤的全部文字和图形范围在预览内部定位；多行消息高于可视区时优先显示其箭头。仅滚动图的容器，不滚动整个页面，不改变 scale 或重新布局。用户减少动画时采用即时滚动，否则用短而克制的滚动；交互正确性不能依赖动画结束事件。

## 5. 分支选择

- 每个顶层 alt 有单独的原生 select，标签来自源码，多个 block 显示不同编号与标签。
- 默认选第一条，始终提示 This is a presentation path; conditions are not evaluated。
- 用户切换后立即暂停、回到 Step 0 / 新 N，更新所选路径，但图的位置不变。
- 两条 case 不连续播放；未选分支始终不进入步骤列表。
- v0.1 无条件求值、嵌套分支或同时比较两条播放路径的操作。

## 6. 控件与键盘规则

| 控件 | 行为 | 禁用条件 |
| --- | --- | --- |
| Render | 编译当前输入，新成功结果从总览开始 | 正在编译 |
| Previous | 暂停并回到前一步 | 无有效结果、stale、busy 或 index=0 |
| Next | 暂停并前进一步 | 无有效结果、stale、busy 或 index=N |
| Play | 在当前步恢复；总览/末尾从 Step 1 开始 | 无有效结果、stale、busy 或 N=0 |
| Pause | 保留当前步并停计时器 | 用作正在播放时的 Play 按钮标签 |
| Reset | 暂停并回到 Step 0，保留分支选择 | 无有效结果、stale 或 busy |
| Focus | 切换显示方式 | 无有效结果或 busy |
| Export HTML | 下载当前成功结果，从总览暂停打开 | 无有效结果、stale、busy 或导出处理中 |

自动播放每 1500 ms 前进一步，末尾自动停止。手动 Next/Previous 均暂停；浏览器标签页隐藏也暂停，不自动恢复。

键盘：播放器区域聚焦时 Left=Previous，Right=Next，Space=Play/Pause，Home=Reset。textarea、input、select、contenteditable 聚焦时不拦截这些按键；原生按钮的 Space/Enter 行为不能被全局 handler 重复执行。

控件具有可访问名称、明显焦点和合理点击区域。播放状态和步骤计数以适度的 aria-live 更新，自动播放不逐字朗读整张图。当前消息文本始终可在图外访问。

## 7. 错误与加载状态

| 情形 | UI 反馈 | 恢复方式 |
| --- | --- | --- |
| 空输入 | Paste a sequence diagram to continue | 保留编辑器，输入后 Render |
| 不支持语法 | 第 X 行：当前版本不支持 opt 等，并展示具体语句 | 修改输入，或加载支持案例 |
| 结构/引用错误 | 行列位置、原因、相关参与者或 block | 点击诊断时定位源码，不丢失内容 |
| 超限 | 源码显示实际 UTF-16 长度；语义项显示已检测数量下限与允许上限，不截断 | 用户缩小图 |
| Mermaid 布局/映射失败 | Could not prepare this diagram for playback；具体可读原因 | 保留源码，再次 Render 或换案例 |
| 编译中 | Rendering…，相关控件禁用 | 成功或失败后恢复；过期结果不覆盖新草稿 |
| 导出失败 | Export failed；可重试原因 | 保留有效预览与源码，允许重试 |
| 首次示例失败 | Example could not load，Retry | 重试或输入自己的图 |

如果已有成功预览，新 Render 失败时旧图可保留用于参考，但要显著标注 Last successful render，播放与导出禁用。不能把旧预览当成新输入成功，错误提示不只是 console 日志。

## 8. 默认视觉

仅做一种清晰的浅色主题。建议设计起点：页面背景 #F8FAFC，面板白色，主要文字 #0F172A，次要文字 #475569，强调色 #2563EB，错误色 #B91C1C；这些是设计值，实际颜色组合仍需对比度检查。

- 正文使用系统字体，代码使用系统等宽字体，不下载网络字体。
- 参与者名称和消息尽量保持清楚；长文本按渲染路线允许的宽度折行，图外说明提供完整文本。
- 当前消息通过颜色、粗线条与明确标记识别，不使用持续闪烁。
- 不加入粒子、3D、飞行小球、音效或主题切换；先让讲解动作和信息层次成立。
- 尊重 prefers-reduced-motion。自动播放仍可使用，视觉过渡和滚动动画关闭。
- 颜色、字号、间距等 token 定义在 src/player.css（随导出文件嵌入）；取值、对比度与样稿见 [design/README.md](../design/README.md)。按用户本轮美观改进要求，Mermaid 固定为 base + 受控 themeVariables：参与者浅灰底灰边、深色文字，Note / alt 淡蓝色，与蓝色当前步骤保持协调。关闭渐变，不改 Arial 字体与布局参数，仍只提供一种浅色主题；Web 与新导出一致。历史导出文件不会自动更新。

## 9. 导出文件的体验

单文件打开后展示 SeqShow、完整图、分支选择、当前步骤说明和播放控件；没有编辑器，没有登录，没有下载依赖的提示。

保留导出时的分支选择，默认 Step 0、暂停、Focus 开启。允许收件人切换分支。当前生成过程不把原始源码默认写入文件，只保留播放所需的语义内容；用户应知道消息、Note 和参与者标签会包含在产物中。

首版文件名 seqshow-presentation.html；重复下载按浏览器自身规则处理。生成时按钮展示 Exporting… 与 aria-busy，禁止重复触发；失败保留成功图和草稿、展示错误并允许重试，清理已创建的 Blob URL。文件应在 file:// 打开并断网时运行。不能把 http 服务环境测试通过当作离线文件通过。

预览的浏览器宽度和导出文件宽度可以不同，但步骤、选中路径和数据相同。窄屏导出也需要保留可操作的控件和图内滚动。

## 10. 必须人工看过的场景

登录成功、登录失败、Note、自调用、重复消息、中文长标签、长消息、多个 alt、360/390/768/1280 px 布局、键盘路径、减少动画、语法错误与恢复、导出断网打开。

视觉检查记录真实截图与观察；DOM 断言通过不能代替看图是否裁切、重叠或箭头不清楚。检查清单与截图命名见 TESTING。

## 11. 面向新用户的互动展示

独立入口 `showcase.html`，主编辑器提供 Showcase 链接，打开新标签保留当前编辑器草稿。面向首次接触者展示五个章节：全图总览、逐步播放、路径选择、Focus、单文件离线分享。展示页采用发布会式深色外框：顶部为品牌、五章节进度条与全屏 / 编辑器入口，其下一条横向讲解带（章节标题、说明与唯一主操作），真实播放器作为白色舞台占满其余高度；播放器内部仍是唯一的浅色主题，深色只用于外框。桌面在一屏内完成，图区吸收剩余高度，1280×720 播放控件可见；窄屏上下排列，不把长图缩成不可读小字，允许图内滚动。图区上方的六个服务标签兼作“服务雷达”，按当前步骤标出 FROM / TO / SELF / NOTE，总览时全部清除；步骤栏显示当前端点。

复杂订单案例包含六个参与者、30 条全图 Message / Note、两个独立顶层 alt，共四种路径组合；首次支付成功路径 20 步，支付恢复路径 24 步。恢复路径是首次拒绝后使用另一种方式重新授权成功，然后进入共同的订单提交与履约流程；不把最终支付失败和发货连在一起。图表示示意流程，不调用服务或判断条件。

章节切换暂停，恢复两条默认路径、开启 Focus，再用共享播放器的 SEEK 定位章节消息；首章恢复总览和图容器左上角。用户仍可自由操作原生播放器。支付章节按钮在首次成功和恢复路径之间切换，再定位所选响应；Focus 章节按钮只切换 Focus。离线章节按钮真正下载当前图和路径的 HTML，从总览暂停打开。章节故事文案不写入用户的导出文件。

全屏使用浏览器原生 Fullscreen API，支持退出，拒绝时显示可恢复提示。打开编辑器入口在新标签加载 `?example=checkout`；其他未知参数回退登录案例。展示页编译失败保留讲解并提供重试。素材与讲稿见 [展示讲稿](release/showcase.md)。
