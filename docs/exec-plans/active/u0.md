本轮按用户要求在 `ffang/showcase` 准备新的复杂案例与发布会式互动入口，见[执行记录](../completed/showcase.md)和[展示讲稿](../../release/showcase.md)。新配色、复杂动图和单文件样本已在本地生成；不视为 main 已合并或站点已发布。

建议继续信号：至少 3 位用于真实内容、至少 2 位再次使用。这是产品试验约定，样本不足时不能声称验证了大众需求。

采用数、重复使用、仓库访问与 stars 分开记录。100 stars 是用户希望达到的传播目标，未实测前不填入完成结果；不刷星、不机械群发，不添加采集用户源码的分析 SDK。

| 指标 | 起点 | 后续记录 |
| --- | --- | --- |
| 真实用户试用 | NOT RUN | 日期、实际人数、自带输入情况 |
| 内容采用 / 再次使用 | NOT RUN | 自愿反馈与可验证实例 |
| GitHub 访问 / stars | NOT RUN | 日期、来源和真实计数 |
| 公开站点 / Release / 社区发布 | NOT RUN | 所有者批准的入口与实际链接 |
