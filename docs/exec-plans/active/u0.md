# U0：公开发布与真实使用验证

状态：NOT STARTED。更新：2026-10-07。本计划不自动授权合并、部署站点、发布 Release、发帖或联系他人。

## 前置条件

- M5 技术验收完成，证据见 [M5](../../validation/M5.md)。
- 所有者审阅 `ffang/m5-release-validation` 的累计 M4 / M5 变更，并明确批准本次合并 main。
- 确定希望公开的入口和发布素材；离线登录文件及真实截图已准备，不能把本地 preview 当已公开的站点。

## 待做事项

1. 合并批准后按仓库规则合入 main，确认安装、README 截图及离线演示来自最终版本。
2. 准备面向 GitHub 开发者的简短演示：粘贴自己的图、选择失败路径、Focus、导出、断网打开。用实际效果说明用途。
3. 由所有者确定是否发布托管演示与 GitHub Release，选择发布渠道并批准具体素材；发布前的准备可先完成。
4. 获得联系或发帖的明确授权后，邀请约 10 位技术写作者或开源维护者，用他们自己的图试用。
5. 根据自愿反馈记录是否成功 Render / 导出、是否用于真实技术内容、是否再次使用、遇到的语法或性能问题。

## 判断方式

建议继续信号：至少 3 位用于真实内容、至少 2 位再次使用。这是产品试验约定，样本不足时不能声称验证了大众需求。

采用数、重复使用、仓库访问与 stars 分开记录。100 stars 是用户希望达到的传播目标，未实测前不填入完成结果；不刷星、不机械群发，不添加采集用户源码的分析 SDK。

| 指标 | 起点 | 后续记录 |
| --- | --- | --- |
| 真实用户试用 | NOT RUN | 日期、实际人数、自带输入情况 |
| 内容采用 / 再次使用 | NOT RUN | 自愿反馈与可验证实例 |
| GitHub 访问 / stars | NOT RUN | 日期、来源和真实计数 |
| 公开站点 / Release / 社区发布 | NOT RUN | 所有者批准的入口与实际链接 |

未执行项保持未执行。若反馈是静态图足够，重新审视讲解场景；若有人反复使用但曝光不足，再改进发布入口。
