# M4：单文件离线 HTML 导出验收

状态：COMPLETE。日期：2026-10-07。基线：main 的 `340110d`；实现分支：`ffang/m4-offline-export`。本阶段不合并 main，不完成 M5 或发布站点。

## 交付

复用既有 esbuild 运行包和同一个 `player.ts` / `core/playback.ts`，没有复制播放算法、函数 `toString` 或外部依赖。产物内联规范化 SVG、语义模型、分支选择、CSS 与运行包；不默认包含原始源码，消息/参与者/Note 标签仍是导出内容。

导出前通过 `initialPlayback` 校验并补全保存的分支选择，非法 case/alternative 在生成阶段明确失败。打开后固定总览、暂停、Focus 开启，保留导出路径，收件人仍可选择其他分支。导出不改变编辑器中的步骤、播放与 Focus 状态。

SVG 安全检查原样提取到 `renderer/svg-safety.ts`，供 Renderer 与 Export 共用；Mermaid 的结构、角色和语义绑定仍集中于 `mermaid-adapter.ts`。这样 Export 和序列化测试无需加载 Mermaid 或访问模块顶层 canvas，安全白名单与资源规则没有放宽。导出保留必要 style/defs/marker，同文件引用有效；资源依赖和可执行 SVG 被拒绝。

数据使用独立 JSON script 和 `safeJson` 编码，处理 `<`、结束 script 标签及 U+2028/U+2029；引号、反斜线和 `&` 通过真实文件 round-trip 保留。可信运行包与 CSS 另有结束标签检查。导出 CSP 限制外部资源，不替代编码和 SVG 校验。

下载展示 `Exporting…`、禁用状态与 `aria-busy`。构造 Blob 或触发下载失败时保留源码和成功预览，显示可恢复错误；生成的 Blob URL 即使点击失败也在 finally 中安排释放。源码 stale / Render busy / 无结果仍禁止导出。

共享 CSS 将长图高度限制和窄屏选择器约束用于离线页；新增播放器键盘提示、根节点名称和焦点轮廓。滚动在图内部发生，布局不重算。

## 实际检查

环境：Windows、Node 22.14.0 / npm 10.9.2、Mermaid 12.1.0、Playwright 1.63.0；无依赖/lockfile 变更。固定结果和命令见 [m4-report.json](m4-report.json)，M0 完整回归见 [m4-m0-report.json](m4-m0-report.json)。完整 production 报告和日志位于忽略的 `artifacts/m4/`。

Chromium production 检查新增十项 M4 用例：

- 真正下载失败路径文件，在全新断网 `file://` 上下文打开；初始分支、总览、暂停和 Focus 正确。
- Web 与导出分别执行同一串 Next/Previous、Play/Pause、tick、末尾重播、Reset、Focus、选择分支、键盘动作；状态、当前内容、端点、各 SVG phase、按钮和选择相同，几何不变。
- 两个独立 alt 的四种不等长路径；空选中路径的 0/0 与禁用控制，可切回有步骤路径。
- 360/390/768/1280px 中文别名、长 case、URL、自调用、重复消息与 Note；无全页意外横向溢出，图内滚动，减少动画。
- 直接构造包含 `</script><script>`、`<img src>`、引号、反斜线、中文、U+2028/U+2029 的导出数据，并打开真实文件：文本保留，仅两个可信 script 元素，没有注入节点、执行或远程请求。
- 调用真实 Export 边界拒绝不安全 SVG、事件属性、资源、CSS URL/import、非法分支及可信 bundle 结束标签；没有添加生产测试开关。
- 注入一次性的 Blob 创建与 anchor 点击失败，核验草稿/播放保留、busy、错误、重试与 URL 清理。

WebKit 重点范围为登录动作对照、两个 alt、空路径、390px 中文与构造数据五项；Windows 上使用阻断 HTTP(S)/WS(S) 并观察尝试的离线方式，`setOffline` 会阻断 file://，不能声称该方法通过。Chromium 使用真正 `setOffline`。所有新离线上下文同时检查实际请求尝试、可执行资源节点与页面异常，不借用编辑器已加载的资源。

Firefox 本轮未运行，既有 Windows 二进制启动限制保留。完整跨浏览器发布验收仍由 M5 负责。Vite 的 Mermaid 大 chunk 提示保留。
