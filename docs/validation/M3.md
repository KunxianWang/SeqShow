# M3：编辑器与共享播放器验收

日期：2026-10-07。状态：COMPLETE。M4/M5 尚未完成，不表示完整 MVP 或发布兼容性通过。

## 实现与边界

正式页面提供原生 textarea + Preview、Render、六个原创案例、分支选择、当前消息与真实端点说明、Focus、播放器键盘与响应式布局。选择备选路径不会判断业务条件；只有所选路径进入播放。重复消息、自调用和四种 Note 位置均由真实 Parser 模型生成。

编辑源码立即暂停并标识旧结果，禁用播放与导出。Render 保留草稿，失败显示可点击的行列诊断并选择对应字符；修正后从总览恢复。异步成功与失败都校验草稿 revision，初次加载期间的新输入也不会被示例覆盖。示例替换使用原生 dialog，Cancel/Escape 保留非空修改；刷新不保存草稿，页面给出复制提示。

共享 player 管理计时器、销毁、可用状态和键盘边界：编辑/表单输入不受干扰，按钮 Space 保留原生行为，避免重复推进。当前步骤仅滚动图内部，SVG 坐标与 viewBox 不变；减少动画偏好使用即时滚动。旧结果仍可切 Focus 作为参考。
