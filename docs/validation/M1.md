# M1 工具链验收

日期：2026-10-07。范围：在当前目录建立单包 Vite / TypeScript 工程、检查命令、登录原型与 production 验证入口。M1 COMPLETE 不代表完整 MVP 完成。

## 交付

- [package.json](../../package.json) 与 lockfile：精确版本、Node engines、全部约定 scripts。
- [tsconfig.json](../../tsconfig.json) 与 [ESLint 配置](../../eslint.config.js)：应用、TS 测试与配置的类型检查；应用和 Node 脚本的 lint。
- [Vite 配置](../../vite.config.ts)：静态构建、严格端口、共享离线运行包的虚拟模块。
- [构建函数](../../scripts/build-player.mjs)：Web 开发、production 和 M0 使用同一个 esbuild 入口；验证运行包不包含包依赖或远程资源。
- [首页](../../index.html)、[main.ts](../../src/main.ts)、[登录模型](../../src/examples.ts)：复用 M0 renderer/player/export，生产页无需调试 API，不从 tests 目录导入模型。
- [Vitest 配置](../../vitest.config.ts) 与 [Playwright 配置](../../playwright.config.ts)：非 watch 测试、隔离 production preview，三浏览器项目均保留。
- tests/unit、tests/integration、tests/e2e：当前基础测试入口；继续保留 M0 的八个 fixture 与期望路径。

开发与生产都内联同一播放器的构建结果，production 另输出 dist/export-player.js。Vite 跟踪 esbuild 实际输入文件；播放器源码改变时，页面和导出脚本一起刷新。本轮用临时按钮文案改动验证了这一点，完成后按原始字节恢复文件，没有保留测试改动。

登录模型从 M0 fixture 中提取到应用模块；M0 仍用独立列出的期望步骤 ID 验证它，没有复制另一份登录流程。M1 暂不提供用户 Mermaid 输入、正式编辑器、完整案例选择或完整产品诊断。

## 环境与命令

实测 Node 22.14.0 / npm 10.9.2；支持 Node ^22.13.0、^24.0.0 或 >=26.0.0，与 ESLint/Vitest 的 engines 一致。锁定 Vite 8.3.3、TypeScript 6.0.3、Vitest 5.0.3、ESLint 10.12.0、typescript-eslint 8.71.1；保留 Mermaid 12.1.0、Playwright 1.63.0、esbuild 0.28.2、KaTeX override 0.18.2。

registry 中 TypeScript 最新为 7.0.2，但当前 typescript-eslint 的支持范围为 >=4.8.4 <6.1.0，因此选择 6.0.3；不强装不受支持的版本。

```powershell
npm ci
npm run dev
```

开发服务为 http://127.0.0.1:5173。生产预览先运行 `npm run build`，再 `npm run preview`，地址为 http://127.0.0.1:4173。端口占用会直接报错，不自动换端口；M0 preview 使用同一个 4173，不能同时启动。

```powershell
npx playwright install chromium
npm run typecheck
npm run lint
npm test
npm run test:e2e
npm run test:m0
```

typecheck 覆盖 src / tests TypeScript 及 Vite/Vitest/Playwright 配置；Node .mjs 脚本通过 lint 与真实运行核验，checkJs 未开启。lint 不忽略测试文件，也没有用禁用规则掩盖 M0 的显式 any；为 M0 暴露的 API 补了实际推导类型。

`test:e2e` 先构建，再在 4174 启动隔离 preview，默认 Chromium，不复用当前 4173 页面或旧产物服务器。可选浏览器先 build 再执行：

```powershell
npx playwright install firefox webkit
npm run build
npx playwright test --project=webkit
npx playwright test --project=firefox
```

## 修复与剩余限制

1. 初次 lint 指出 M0 的 any 与无用转义，已修正后通过，不关闭检查。
2. 首次 WebKit 两 worker / 默认 30 秒导致超时。trace 中 Windows 驱动的一些 goto/click 花费数秒，串行与 90 秒上限后两项分别在约 24 / 23 秒通过。没有使用 force click 绕过可操作性检查。
3. 干净安装最初失败，Windows 正在占用本项目 esbuild.exe。停止旧 M0 预览后 npm ci 成功，没有删除无关路径或改变系统权限。
4. Mermaid 仍构建其官方包的其他图布局 chunk；体积提示保留，没有提高阈值掩盖。完整 Web 体积/性能评估留给 M5；离线播放器保持独立且不含 Mermaid。
5. Windows WebKit 的 setOffline/file:// 限制与 Firefox 启动问题延续 M0，不能据此声称完整跨浏览器发布验收通过。
