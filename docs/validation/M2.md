# M2 Parser / Model / Playback 验收

日期：2026-10-07。范围：受限 Mermaid 源码解析、诊断、引用与限额、纯播放状态，以及接入固定 Mermaid 适配层。M2 COMPLETE，阶段验收已通过；完整编辑器属于 M3，完整 MVP 尚未完成。

## 实现入口

- [parser.ts](../../src/core/parser.ts)：parseSequence 返回模型或首个错误；不依赖 DOM，不向 Mermaid 传递原始输入。
- [playback.ts](../../src/core/playback.ts)：初始化、路径派生与纯状态转换；非法路径和 SEEK 明确拒绝。
- [player.ts](../../src/player.ts)：共享 DOM 控件与唯一 1500 ms 计时器，Web/导出使用同一转换函数。Focus 仅改变显示。
- [examples.ts](../../src/examples.ts)：登录流程以 Mermaid 源码保存，实际页面使用解析结果。
- [mermaid-adapter.ts](../../src/renderer/mermaid-adapter.ts)：内部布局 ID 避开 Mermaid 关键字，仍校验端点、标签、图形类型、数量和绑定；未放宽 SVG/导出安全检查。

Parser 支持声明与别名、actor、隐式参与者、实/虚线消息、自调用、四种 Note、多个顶层单层 alt/else。显式参与者优先排列；Note 可以引用后面的声明或消息端点。生成 ID 使用 step:1、alt:1、alt:1:first/second，重复文字仍为不同步骤。

源码行/列从 1 开始，列按 UTF-16 单元计数；支持 LF、CRLF、CR 与缩进。诊断区分空输入、图类型、语法、支持范围、重复声明、未知引用、分支结构、无步骤及四项超限。遇到首个错误即返回，不恢复部分模型。每个 case 标签非空，case 可有零步，但整图必须有步骤。

消息/Note 的语法冒号可消费一个格式空格，其后的完整文本不 trim；额外前后空格、中文、URL、内部冒号、普通分号与标点均保留。不支持 HTML/富文本、配置、激活、其他箭头、嵌套分支、分号多语句等。

## 发现与修正

1. 最初贪婪的 ID 匹配会把 API-->>U 读为 API- 的实线消息。改为优先识别最长受支持箭头；手写模型与连字符 ID 测试能独立检出该问题。
2. end 是合法产品 ID，但 Mermaid 将消息端点中的 end 当成关键字。适配层统一生成 seqParticipant1 等布局 ID，并按该映射校验 SVG；模型、参与者高亮及导出语义仍保留原始 ID。
3. 原有非法分支测试仍引用手写 auth ID。随登录真实解析接入更新为 alt:1，保留拒绝非法选择的断言。

没有删减产品 ID 字符范围，没有跳过失败场景或降低映射校验来取得通过。
