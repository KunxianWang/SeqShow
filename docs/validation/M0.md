# M0 验证记录

日期：2026-10-06（本地）；机器可读报告使用 UTC 时间。范围仅为技术路线验证，不是完整 MVP 验收。

## 结论

保留 **Mermaid 12.1.0 + 集中 SVG 适配层** 的路线。手写语义模型可以绑定完整时序图，播放器只更新语义属性，不重新布局；同一播放器可以内联到单个 HTML，直接在 file:// 中使用。

主验收在 Chromium 完成。WebKit 采用远程请求拦截验证本地文件；Firefox 尚未验证，详见下文。M1–M5 仍须实现并验收，尤其是用户输入 Parser、编辑器、production 构建与正式浏览器范围。

## 交付与适配假设

| 文件 | 职责 |
| --- | --- |
| [model.ts](../../src/core/model.ts) | Message、Note、两条 case 的 Alternative 与参与者模型 |
| [playback.ts](../../src/core/playback.ts) | 默认分支与选中路径的纯步骤派生 |
| [mermaid-adapter.ts](../../src/renderer/mermaid-adapter.ts) | 安全标准输入、文本折行、SVG 校验与语义绑定 |
| [player.ts](../../src/player.ts) | Web / 导出共享的控件、计时器与高亮 |
| [export.ts](../../src/export.ts) | 单文件 HTML 组装与 JSON 数据编码 |
| [export-player.ts](../../src/export-player.ts) | 内联运行包入口，只导入共享播放器，不包含 Mermaid |
| [fixtures.ts](../../tests/m0/fixtures.ts) | 手写语义模型及独立列出的期望路径 ID |
| [m0.mjs](../../scripts/m0.mjs) | 构建、预览、真实浏览器与 file:// 断网检查 |

固定配置为 strict、default theme、classic look、关闭底部参与者镜像与绝对 marker URL。为避免实体被拆分，禁用 Mermaid 自动折行，先以浏览器 Canvas 测量 220px 的纯文本行，优先空格边界，长词/中文按 Intl.Segmenter 的 grapheme 边界折行；再编码标点与插入适配层生成的 `<br/>`。这不是允许用户输入 HTML。参与者框高度由最长别名的行数确定，只在整图渲染时设置。

绑定依赖以下 **12.1.0 实测结构**，升级必须重新验证：

- message 的 line/path 具有 data-et=message、data-id、data-from、data-to；箭头 class 区分实线/虚线，自调用为 path。
- 事件 ordinal 包含 alt、else、end，Note 也占一个事件。它仅用于定位候选；数量、角色、箭头形状和完整文本必须再校验。
- messageText 是紧邻对应 line/path 前的连续 text 兄弟节点；支持多行，不按文本搜索或在所有箭头中盲取第 N 个。
- Note 是带语义事件 ID 的 g，包含 rect.note 与纯 SVG noteText。
- alt 框的 control-structure ID 对应 end 事件；验证 alt 标记、五条框线、两个 case 的全部标题文本。
- participant / actor 和 life-line 带参与者 ID；每个恰好一个，校验 kind 与别名。

映射后增加 data-seq-step / participant / alternative / case。播放器不读取 Mermaid 的内部 class 或事件 ordinal。缺失、重复、角色/文本不符的 SVG 拒绝播放。

## 检查内容

8 个 fixture 覆盖线性请求/返回、登录、actor/alias、重复文本、自调用、四种 Note、中文长文本、两个顶层 alt、不同长度路径、单步边界，以及直接构造的恶意/特殊字符标签。HTML 标签样例仅验证底层输出编码；未来 Parser 仍必须按 PRODUCT 拒绝 HTML 输入。

每条路径逐步核验：

- 期望步骤 ID、Message/Note 各占一步、总览没有当前步骤、只突出选中路径中的当前步骤。
- 当前收发双方或 Note 对应参与者；未选中 case 保留在全图但不播放。
- 每一步、分支选择与 Focus 切换前后，viewBox 和图形 getBBox 不变；导出前后 SVG 几何一致。
- 播放立即到第一步，1500ms 推进，暂停/继续保留位置，末尾停止、再次播放回到第一步，手动前进/后退暂停。
- Focus 不重置步骤或暂停自动播放；改变路径暂停并回到总览；页面隐藏事件暂停。
- 从正在讲解的非默认路径导出，重新打开时总览、暂停、Focus 开启；之后可切换路径并完整播放。
- 390px 宽度的图内横向滚动。桌面与窄屏截图已人工查看；正式界面与完整无障碍检查留给 M3/M5。

14 个负向检查覆盖 script、foreignObject、image、animate、链接、事件属性、外部 href / CSS URL、CSS 转义，以及消息缺失、重复、错误角色、错误文本和错误 case 标题。SVG 元素使用允许列表；资源只允许指向已有 ID 的同文件片段；拒绝外部引用、CSS import / font-face / 转义等。保留纯 SVG 的 defs、marker、symbol、use。

导出只包含 SVG、语义模型、CSS 与构建生成的共享播放器 JS，不写入原始 Mermaid 源码，也不包含 Mermaid/KaTeX 或 CDN。JSON 的 `<`、U+2028、U+2029 被编码；标签用 textContent 写入。测试观察远程请求尝试，不能仅靠阻断请求判定成功。

## 浏览器结果与限制

精确版本、fixture 计数、导出大小与运行时间见 [m0-report.json](m0-report.json)：每个浏览器 8 个 fixture、12 条路径、66 个步骤状态，导出播放器 JS 为 3057 字节。锁文件 `npm ci` 重装后的 Chromium 最后复验见 [m0-clean-install-report.json](m0-clean-install-report.json)。

| 浏览器 | M0 状态 | 说明 |
| --- | --- | --- |
| Chromium 153.0.8010.12 | PASS | 全新上下文 setOffline(true)，再打开真实 file:// 导出；远程请求尝试为 0 |
| WebKit 26.6 | PASS，替代断网方法 | Windows 上 setOffline(true) 导致 file:// navigation internal error；用全新上下文拦截并拒绝全部 HTTP(S)/WS(S)，本地文件可用，远程请求尝试为 0 |
| Firefox 155.0 | NOT RUN | 官方 Playwright v1543 包无法启动；Windows SideBySide 日志显示找不到 mozglue 从属程序集。重新安装同版本仍失败 |

WebKit 的替代验证不等同于 setOffline 模式通过，也不能据此声称实际 Safari 已完成兼容验收。Firefox 未验证不是应用测试通过。M5 发布前必须补齐计划要求的浏览器范围；不能将这些记录作为发布验收完成。

初次 npm audit 发现 Mermaid 的 KaTeX 范围包含低危 GHSA-238p-pmpm-9mq7。未采用强制降级 Mermaid；锁定 KaTeX override 0.18.2 后，本轮 npm audit 为 0 个已知漏洞。数学语法不在范围内，文本中的 $$ 按字面显示；后续升级仍复核 lockfile 与 fixture。
