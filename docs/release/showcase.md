# SeqShow：首次认识产品的展示讲稿

状态：本地展示与素材已实现；位于 `ffang/showcase`，未合入 main、未公开部署。公开发布、Release 与对外传播不属于本次执行。素材为真实生产代码截图，不是设计稿。

## 打开方式

```sh
npm run build
npm run preview
```

打开 http://127.0.0.1:4173/showcase.html 。建议桌面 1440×1080 或更大的可用视口，点击“全屏展示”；1280×720 的播放控件仍在视口中。手机上下排列，图在自己的容器中滚动。用主按钮完成本章演示，用左侧章节或底部前后按钮切换章节。

“打开编辑器”在新标签加载 checkout，不覆盖已有编辑器草稿。首次打开编辑器仍默认短登录案例，适合学基本语法；复杂案例在 Example 下拉中可选。

## 90 秒讲解顺序

| 时间 | 画面 / 操作 | 建议讲的话 |
| --- | --- | --- |
| 0–15 秒 | 第 1 章，总览与六个服务标签 | “技术文档里的时序图往往一屏全出现。你准备开始讲，但听众不知道先看哪里。SeqShow 把同一张图变成逐步讲解的演示。” |
| 15–30 秒 | 点“开始这段讲解”，再点“讲解下一步”；也可点 Play / Pause | “这是一笔订单，经过库存、支付和异步履约。现在只讲提交请求，再讲订单服务的自调用。可以暂停、回退，节奏由讲解者决定。” |
| 30–50 秒 | 第 3 章，点“切换到支付恢复路径”；Next 看更换支付方式，再切回 | “第一次支付被拒绝，换一种方式后重新授权。只播放所选路径；未选路径留在原图里，但不会串入下一步。切换不会重新排布整张图。” |
| 50–65 秒 | 第 4 章，Focus 对比按钮来回点 | “事件抵达履约服务时，突出当前消息和参与者。其他信息仍然可读。Focus 只改变强调，不会改变步骤或业务路径。” |
| 65–85 秒 | 第 5 章，点下载；直接打开下载的 HTML，操作播放器 | “图、路径和播放器被装在一个 HTML 里。发给同事，直接打开，不安装工具，没有网络也能播放和切分支。” |
| 85–90 秒 | 右上角打开编辑器 | “接下来，把示例换成你自己的 Mermaid 时序图，Render，然后开始讲解。” |

两条分支都只有一层，不判断真实条件。案例覆盖六个参与者、30 条全图消息 / Note、两个独立 alt；四种组合的所选路径为 20 或 24 步。支付恢复成功后才汇入共同流程，履约延迟是另一项独立选择。本例是讲解素材，不是生产支付或物流架构的完整实现。
