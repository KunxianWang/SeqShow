Mermaid sequence diagram
Supported syntax

One statement per line, starting with sequenceDiagram. Use ASCII participant IDs; labels and messages can be Chinese.

actor U as User
participant API
U->>API: Request
API-->>U: Response
Note over U,API: Plain text
alt success
  API-->>U: Done
else failure
  API-->>U: Error
end

Also: self calls; Note left of / right of / over one or two participants; multiple top-level alt blocks; whole-line %% comments.

Limits: 50,000 UTF-16 units · 20 participants · 200 messages / Notes across all paths · 10 alt blocks.

Unsupported syntax

Nested alt, opt / loop / par, activation, create / destroy, autonumber, rect, other arrows, multiple statements on one line, HTML / rich text, frontmatter, directives and click / links.
